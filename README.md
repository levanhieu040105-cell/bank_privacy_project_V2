# bank_privacy_project_V2
This project evaluates the privacy-preserving capabilities of a banking data processing pipeline designed to protect the *Vietnam Banking Churn 2025* dataset. Our assessment focuses on data resilience against advanced inference threats simulated by state-of-the-art Transformer architectures: PhoBERT, ViDeBERTa, XLM-RoBERTa, and mDeBERTa-v3.
